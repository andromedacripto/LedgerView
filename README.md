# LedgerView

DApp built on the **Base Network**, allowing users to view Ethereum wallets and balances in ETH, USDC and USDT.

## Features

- Connect any EVM wallet on Base Network
- View ETH and ERC-20 token balances and Transactions
- Responsive and user-friendly interface
- Built with React, Vite, and Tailwind CSS

## Demo

[Live Demo on Netlify](https://ledgerview.netlify.app/)

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS  
- **Blockchain:** Base Network (EVM-compatible)  
- **Wallet Interaction:** Ethers.js
